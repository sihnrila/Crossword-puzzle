# 십자말풀이 게임 (Crossword Puzzle Game)

## 📋 프로젝트 개요

모바일 최적화된 십자말풀이 게임으로, 국립국어원 및 시도교육청 어휘 데이터를 기반으로 한 교육용 퍼즐 게임입니다.

## ✨ 주요 기능

### 1. 게임 모드
- **시작하기**: 단일 시작 버튼으로 게임 시작
- **난이도 선택**: 초급, 중급, 고급 3단계
- **격자 크기 선택**: 6×6, 8×8, 10×10 고정 크기

### 2. 힌트 시스템
각 단서마다 3가지 힌트 제공:
- **힌트 1**: 품사 | 뜻풀이
- **힌트 2**: 용례
- **힌트 3**: 초성 (한글 초성 추출)

힌트는 슬라이드 형태로 제공되며, 이전/다음 버튼으로 탐색 가능합니다.

### 3. 입력 방식
- **직접 입력**: 모바일 가상 키보드를 통한 직접 입력
- **자동 분배**: 입력창에 전체 단어를 입력하면 자동으로 각 셀에 분배
- **중복 글자 체크**: 기존 값과 불일치 시 경고 표시 및 값 보호

### 4. 게임 기능
- **단서 선택**: 가로/세로 단서를 클릭하여 선택
- **자동 이동**: 정답 입력 시 다음 단서로 자동 이동
- **교차 단어 처리**: 교차하는 단어의 글자 공유 및 보호
- **정답 확인**: 단어 확인 및 전체 확인 기능
- **단어 공개**: 현재 단서의 정답 공개
- **퍼즐 초기화**: 입력한 내용 초기화

### 5. 설정 기능
- **타이머**: ON/OFF 설정, 페이지 비활성화 시 자동 일시정지
- **자동 체크**: 입력 시 자동으로 정답 확인
- **채워진 칸 건너뛰기**: 이미 채워진 칸 자동 건너뛰기
- **단어 끝 이동 규칙**: Always / IfComplete / Never
- **효과음**: ON/OFF 설정
- **배경음악**: ON/OFF 설정

### 6. UI/UX
- **반응형 디자인**: 모바일, 태블릿, 데스크톱 지원
- **Grid/List 전환**: 격자 보기와 리스트 보기 전환
- **진행률 표시**: 게임 진행 상황 표시 (주석 처리됨)
- **완료 표시**: 완료된 단서는 취소선으로 표시

## 🎮 사용 방법

### 게임 시작
1. 메인 화면에서 "시작하기" 버튼 클릭
2. 어휘 목록 선택 (현재: 시도교육청 정리 어휘)
3. 난이도 선택 (초급/중급/고급)
4. 격자 크기 선택 (6×6/8×8/10×10)
5. 게임 시작

### 게임 플레이
1. **단서 선택**: 왼쪽 단서 리스트에서 가로/세로 단서 클릭
2. **입력**: 상단 입력창에 정답 입력
3. **확인**: "단어 확인" 버튼 클릭 또는 Enter 키 입력
4. **힌트 확인**: 힌트 슬라이더에서 이전/다음 버튼으로 힌트 탐색
5. **정답 시**: 자동으로 다음 단서로 이동

### 단서 탐색
- **가로/세로 전환**: 같은 셀을 다시 클릭하거나 Space 키로 전환
- **자동 이동**: 정답 입력 시 교차하는 단서로 자동 이동
- **완료된 단서**: 취소선으로 표시되어 완료 상태 확인 가능

## 🐛 해결된 주요 이슈

### 1. 정답 확인 로직
- **문제**: `selectedLetters` 기반 확인으로 교차 단어 처리 오류
- **해결**: 그리드 값 직접 읽기로 변경

### 2. 교차 단어 보호
- **문제**: 단서 전환 시 교차 단어 값 삭제
- **해결**: `readOnly` 셀 보호 및 값 보존 로직 추가

### 3. 인덱스 불일치
- **문제**: `activeCells` 직접 인덱싱으로 순서 불일치
- **해결**: `getOrderedActiveCells()` 통일 사용

### 4. 입력값 분배
- **문제**: 입력창 값이 그리드에 반영되지 않음
- **해결**: `distributeInputToGrid()` 함수 및 `distributedInputValues` Map 사용

### 5. 슬라이드 표시
- **문제**: 슬라이드 2, 3이 화면에 표시되지 않음
- **해결**: CSS `opacity` 제거 및 위치 조정 로직 개선

## 📝 설정 저장

모든 설정은 `localStorage`에 저장됩니다:
- `score`: 점수
- `timer`: 타이머 ON/OFF
- `autocheck`: 자동 체크 ON/OFF
- `skipFilled`: 채워진 칸 건너뛰기 ON/OFF
- `wordEndMove`: 단어 끝 이동 규칙
- `soundEffect`: 효과음 ON/OFF
- `bgMusic`: 배경음악 ON/OFF
